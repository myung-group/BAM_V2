## 다시 모으는 방법

모으는 스크립트는 이 폴더의 `collect_results.sh`다(작은 파일 `cp`만 한다). 새 결과가 생기면 라벨을 인자로 주어
다시 돌린다: `bash collect_results.sh v3_e20 v3_e70 v3_final`. 그림은 세션 임시 폴더(스크립트의 `SP`)에서
가져오므로, 다른 세션에서는 `SP`를 그림이 있는 곳으로 바꾼다.
